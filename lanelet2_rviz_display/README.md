# Lanelet2 RViz Display

The Lanelet2 Display-Plugin for RViz2 is able to visualize a Lanelet2-Map that is provided via the [lanelet2_map_server](https://gitlab.ika.rwth-aachen.de/fb-fi/its-modules/localization/lanelet2_map_server)/[-_interface](https://gitlab.ika.rwth-aachen.de/fb-fi/its-modules/localization/lanelet2_map_interface).

## Getting started

Before you start the ros2-monitoring container, make sure to mount your lanelet2-maps into `/data/maps`.
After startup of the container, add the display within rviz2 by clicking on `Add` and select the display under the tab `By display type`.
