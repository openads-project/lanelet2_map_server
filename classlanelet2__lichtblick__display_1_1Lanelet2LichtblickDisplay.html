Check for a new or changed Lanelet2 map and publish markers if present.

This function queries the Lanelet2MapInterface for the current map pointer and compares it against the internally stored last_map_ptr_. If a new map is detected (pointer change and non-null), it triggers publishMarker(...) to convert the map into visualization markers.

Called periodically by the node's timer.
